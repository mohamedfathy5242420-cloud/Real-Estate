# Frontend acceptance
سيناريوهات مخطط لها؛ لا يوجد اختبار Angular أو متصفح منفذ.

## FAC-01 — إدارة الكتالوج
Given مدير معروض، When يغير التوفر، Then لا يتغير النشر ضمنيًا.
خطأ كود مكرر يعرض في النموذج ولا يعلن الحفظ؛ بيانات المطور لا تنشئ حسابًا.
اتفاقان فعالان متداخلان على المشروع يرفضان؛ نطاق الاتفاق العام يشمل مشاريع المطور الجديدة،
والمحدد لا يشملها تلقائيًا (D015، D019). تفاصيل الطلب/الرد في F01-S04.
BR-01, BR-02, BR-03, BR-14, BR-15. UC-01. SC-07.

## FAC-02 — عام ومحمي
Given زائر، Then البحث والتفاصيل والأسعار متاحة.
When يطلب معاينة/حجز، Then يلزم الدخول ولا ينشأ طلب غير مصرح.
جلسة منتهية أو حساب آخر لا تكشف موارد العميل. BR-04. UC-02. SC-01, SC-02, SC-03.

## FAC-03 — الإسناد
Given عميل له مسؤول، Then الطلب الجديد يظهر بنفس المسؤول حسب رد الخادم.
الإسناد والنقل للمدير؛ الموظف لا يرى عملاء خارج نطاقه.
Lead فرصة بيع مرتبطة بعميل ومشروع؛ إسناد الموظف الأساسي للعميل ولا يتغير تلقائيًا
لكل Lead جديدة (D020، D022).
BR-05, BR-06, BR-15. UC-03. SC-06.

## FAC-04 — البديل
Given بديل منسق، Then يظهر بانتظار قبول العميل لا كمؤكد.
When يقبل ويؤكد الخادم، Then تعرض الحالة المؤكدة؛ الخطأ لا يغيّرها محليًا.
وقت المقترح لا يتجاوز 30 يومًا، والمدة الافتراضية 60 دقيقة. التأكيد الأول الصحيح فقط
يحجز فترة الوحدة والموظف؛ التعارض يبقي الطلب الآخر Pending لبديل (D023، D024، D026).
BR-07. UC-04. SC-04, SC-05.

## FAC-05 — إعادة الجدولة
Given موعد مؤكد قبل البداية، When ينجح طلب التغيير،
Then القديم ملغى والجديد ينتظر، ولا تبقى بطاقة الموعد القديم مؤكدة.
رفض الخادم بعد حد الوقت يظهر دون تغيير كاذب. BR-08. UC-05. SC-04, SC-05.
PendingConfirmation تنتهي بعد سبعة أيام أو عند المقترح أيهما أقرب؛ البديل غير المقبول
ينتهي عند وقته. Confirmed لا يتحول Expired بمرور الوقت (D025، D028).

## FAC-06 — الخصوصية
Given نتيجة بملاحظات داخلية، Then العميل يرى الحالة دون الملاحظات
في DOM أو نموذج العرض أو الاستجابة المخصصة له. اختبار العقد والخادم مطلوب أيضًا.
BR-06, BR-09. UC-06. SC-04, SC-05.
غياب المطور أو إلغاء الموظف يظهر Cancelled مع السبب والفاعل، وليس CustomerNoShow (D029).

## FAC-07 — الطلب لا يضمن الحجز
Given لم تحدث معاينة، When العميل يرسل طلبًا، Then يعرض انتظار مراجعة لا تأكيدًا.
تغير السعر/التوفر أو timeout يعرض حالة قابلة للفهم دون إرسال مكرر.
BR-10, BR-11, BR-16. UC-07. SC-02, SC-08.

## FAC-08 — المهلة والعربون
Given انتهاء حجز، Then لا تعلن الواجهة توفر الوحدة دون رد حديث للخادم.
تسجيل العربون لا يعرض بيعًا مكتملًا أو عمولة. BR-12, BR-13. UC-08. SC-08.

## FAC-09 — تاريخ العمولة
Given صفقة قديمة، When يتغير الاتفاق، Then تعرض الواجهة snapshot المحفوظ،
لا حسابًا مشتقًا من الاتفاق الجديد. BR-14. UC-09. SC-09.
النسبة تُحسب على سعر البيع النهائي دون الرسوم والإضافات أو مبلغ ثابت؛ Project override
يسبق القاعدة الافتراضية، وحماية Lead الافتراضية 90 يومًا قابلة للتعديل أو الصفر (D016–D021).

## FAC-10 — فشل الإشعار
Given عملية محفوظة، When يفشل تحميل الإشعارات،
Then تبقى حالتها صحيحة ولا تظهر العملية الأساسية فاشلة.
عرض رابط لا يتجاوز ownership check. BR-08, BR-15. UC-10. SC-10.

## Cross-cutting UX
كل سيناريو يراجع على الموبايل وسطح المكتب ولوحة المفاتيح، وتسميات الحقول ورسائل الخطأ والتركيز.
English LTR هو اتجاه النسخة الأولى حسب FE-D007؛ عند إضافة العربية يُختبر RTL. صور أو mocks لا تثبت تكاملًا مع Backend.
