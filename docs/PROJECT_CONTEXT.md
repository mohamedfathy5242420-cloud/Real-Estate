# سياق المشروع
هذا ملخص. المرجع التفصيلي المعتمد للقراءة هو docs/business/README.md وما يربطه من قواعد ورحلات.

## الهدف
منصة لشركة بروكر واحدة تسوق وحدات للبيع من عدة مطورين عقاريين.
الاسم المؤقت BrokerHub. الهدف التعليمي تطبيق موضوعات الكورس تدريجيًا مع فهم ومراجعة كل مرحلة.

## نطاق العمل الحالي
طلب المستخدم بدء Backend بالقراءة من الملفات واتباع نظام العمل.
P01 أُغلقت، وP02 تنفذ الأساس البرمجي وحدود الهوية والصلاحيات قبل مراحل الـBusiness.

## قرارات المستخدم
- Clean Architecture بتنظيم طبقات وأنواع ملفات، بدون Vertical Slice.
- المطور بلا حساب في النسخة الأولى. التواصل معه خارج النظام؛ موظف البروكر يسجل الرد والتحديث.
- العميل له حساب. التصفح والأسعار والتفاصيل عامة؛ طلب المعاينة والحجز يتطلب تسجيل الدخول.
- المدير يوزع العملاء يدويًا؛ العميل غير المسند ينتظر التوزيع.
- طلبات العميل التالية تذهب لنفس الموظف المسؤول. المدير يستطيع نقل المسؤولية مع حفظ التاريخ.
- الموظف يرى الطلبات المسندة إليه، والمدير يرى الجميع.
- العميل يقترح موعد المعاينة وينتظر تأكيد الموظف بعد التنسيق مع المطور.
- عند عدم التوفر يقترح الموظف بديلًا منسقًا؛ قبول العميل يؤكد الموعد.
- الإلغاء أو طلب إعادة الجدولة متاح قبل بداية الموعد.
- طلب إعادة الجدولة يلغي الموعد القديم فورًا ويعيد الطلب لانتظار التأكيد، مع إخطار الموظف وحفظ التاريخ.
- الموظف يسجل تمت المعاينة أو لم يحضر؛ العميل يرى الحالة، وملاحظات المبيعات داخلية.
- طلب الحجز لا يشترط معاينة سابقة. تقديم الطلب لا يثبت حجز الوحدة.

## قواعد المسودة التي وافق المستخدم على اعتمادها للانطلاق
- المطور يملك مشاريع، والمشروع يحتوي وحدات؛ كود الوحدة مميز داخل المشروع.
- اتفاق التسويق يحدد النطاق والمدة وقاعدة العمولة.
- نشر الإعلان منفصل عن توفر الوحدة. نخزن مصدر ووقت آخر تأكيد للتوفر والسعر.
- تأكيد المطور الخارجي هو المرجع للحجز؛ لا نفترض أن مخزون البروكر يمثل كل مبيعات المطور.
- الحجز يحتفظ بالسعر والمرجع والمهلة المؤكدة. البيع المكتمل يسجل كصفقة منفصلة.
- انتهاء الحجز لا يعيد الوحدة إلى متاحة دون إعادة تأكيد توفرها.
- العربون يدفع للمطور خارج النظام، ويسجل الموظف التأكيد. العمولة منفصلة عنه.
- العمولة تحفظ كقيمة وقاعدة حساب وقت اعتماد الصفقة، وتتابع كمستحقة أو محصلة.
- حفظ سجل تغييرات الحالات والإسناد والأسعار المهمة ومن نفذها.

## النسخة الأولى
كتالوج، حسابات وصلاحيات، متابعة عملاء، معاينات، طلبات حجز، صفقات وعمولات، وإشعارات.
تقنية الواجهة Angular، ولها Workflow مستقل داخل front end. العمل الحالي على Backend.
لا إيجار أو بوابة مطورين أو دفع حقيقي أو تعدد شركات بروكر في هذه النسخة.

الحجز/البيع. Q01/Q02/Q03/Q05 حُسمت؛
لا تعاد مناقشتهما أو استبدالهما بافتراضات.
نحسم التفاصيل عند تصميم المرحلة ذات الصلة، دون تعطيل أساس المشروع.
